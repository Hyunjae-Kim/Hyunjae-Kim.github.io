# Hyunjae Kim — academic homepage

Buildless HTML/CSS site for GitHub Pages.

- `index.html`: introduction and two research directions
- `publications.html`: research previews
- `publications/`: individual project pages
- `cv.html` and `assets/Hyunjae-Kim-CV.pdf`: CV

Edit the HTML pages directly. Publication metadata is also recorded in `assets/publications.json` for reference; it does not automatically update the HTML. Research overviews are introductory summaries based on the supplied CV, not full abstracts. Conceptual illustrations are not empirical results. No external fonts, scripts, or analytics are required.

Preview: `python3 -m http.server 8000`

Deploy the main branch, root folder, using GitHub Pages.
